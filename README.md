## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vp51278-afk/demoshopapp.git
```

### 2. Open the project

```bash
cd demoshopapp
```

### 3. Install dependencies

If the project contains a `package.json` file, run:

```bash
npm install
```

### 4. Run locally

Use the development command defined in `package.json`. For many Vite projects, this is:

```bash
npm run dev
```
